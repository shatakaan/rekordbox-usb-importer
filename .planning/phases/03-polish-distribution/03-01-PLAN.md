<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| plist → MainWindow | QSettings values read from ~/Library/Preferences/ at startup; attacker with local user access can modify the plist |
| ImportPlan.selected_playlists → TrackPanel | Plan produced earlier in the same session; no cross-process boundary |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01-01 | Tampering | QSettings usb/last_mount | mitigate | Validate with Path(mount_str).is_absolute() before use; match only by .name (not used as a writable path in session restore — only for auto-select hint) |
| T-03-01-02 | Tampering | QSettings selected_playlist_ids | mitigate | Normalize via {int(x) for x in raw_ids} — rejects non-numeric entries silently; IDs are only used for pre-checking UI checkboxes, not for direct DB writes |
| T-03-01-SC | Tampering | pip/PyPI installs | accept | No new package installs in this plan (QSettings is stdlib Qt, already installed) |
</threat_model>
