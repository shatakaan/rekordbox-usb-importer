    In core/import_controller.py die private Methode `_import_cues(self, db, content, track: TrackRow, mount: Path) -> int` implementieren:

    Rückgabewert: Anzahl geschriebener Cues (für Logging).

    Vorbedingungsprüfung:
    - Wenn `track.analyze_path is None`: `logger.warning("Track '%s': no analyze_path — imported without cues", track.title)` und return 0.
    - `dat_path = (mount / track.analyze_path.lstrip('/')).resolve()`.
    - Path-Guard: assert dat_path unter mount (analog zu file_path-Guard).
    - Wenn `not dat_path.exists()`: `logger.warning("Track '%s': ANLZ file not found at %s — imported without cues", track.title, dat_path)` und return 0.

    ANLZ-Strategie (per D-09, Pitfall 6 — NIEMALS beide):
    - `ext_path = dat_path.with_suffix('.EXT')`.
    - `use_ext = ext_path.exists()`.
    - Wenn use_ext: `anlz = AnlzFile.parse_file(ext_path)`. Tag-Key = 'PCO2'. Entries haben kein status-Feld (alle gelten als enabled).
    - Wenn nicht use_ext: `anlz = AnlzFile.parse_file(dat_path)`. Tag-Key = 'PCOB'. Nur Entries mit `entry.status.intvalue == 4` (enabled).
    - Wenn Tag-Key nicht in anlz: return 0 (keine Cues in dieser Datei).

    Für jeden Entry:
    - `kind = entry.hot_cue` (0=Memory, 1..8=Hot Cue Slot).
    - `in_msec = entry.time`.
    - `out_msec = getattr(entry, 'loop_time', -1) or -1`.
    - `comment = getattr(entry, 'comment', '') or ''`.
    - `id_ = db.generate_unused_id(DjmdCue)`.
    - `uuid = str(uuid4())`.
    - `cue = DjmdCue.create(ID=id_, UUID=uuid, ContentID=content.ID, ContentUUID=content.UUID, Kind=kind, InMsec=in_msec, OutMsec=out_msec, Comment=comment, Color=-1, ActiveLoop=0, InFrame=0, InMpegFrame=0, InMpegAbs=0, OutFrame=0, OutMpegFrame=0, OutMpegAbs=0, ColorTableIndex=0, BeatLoopSize=0, CueMicrosec=in_msec * 1000)`.
    - `db.add(cue)`.

    Import: `from pyrekordbox.anlz import AnlzFile` und `from pyrekordbox.db6.tables import DjmdCue`.

    run_import() erweitern: Nach dem add_content/DjmdContent.create-Aufruf `cue_count = self._import_cues(rb6_db, content, track, self.mount)` aufrufen. `logger.info("Track '%s': %d cues imported", track.title, cue_count)`.
