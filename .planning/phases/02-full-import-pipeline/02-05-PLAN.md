    In ui/main_window.py:

    Imports hinzufügen: `from core.import_controller import ImportController, ImportPlan, ImportResult, TrackImportStatus` und `from PySide6.QtCore import QRunnable, QThreadPool, Signal, QObject`.

    Signal-Relay-Klasse für Background-Thread-Logging (notwendig wegen Thread-Safety — Log-Panel-Kommentar beachten):
    `class _ImportSignals(QObject): progress = Signal(str); finished = Signal(object); error = Signal(str)` — als private Klasse in der Datei definieren.

    QRunnable-Subklasse `_ImportWorker`:
    - `__init__(self, controller: ImportController, plan: ImportPlan, rb6_db)`: Attribute speichern, `self.signals = _ImportSignals()`.
    - `run(self)`: Versuche `controller.run_import(plan, rb6_db)`. `result` → `self.signals.finished.emit(result)`. Bei Exception → `self.signals.error.emit(str(exc))`. Logging-Calls innerhalb run() gehen über Python logger (QLogHandler fängt sie auf dem Main-Thread ab — FALSCH: QLogHandler.emit() darf nicht aus Background aufgerufen werden). Daher: statt `logger.info(...)` direkt in run(): `self.signals.progress.emit("Nachricht")` emittieren; MainWindow-Slot verbindet das mit `self.log_panel`-Anzeige via `logger.info`.

    In MainWindow.__init__ (oder _build_ui):
    - `self._pdb_db = None` (referenz auf aktuelle PdbDatabase).
    - `self._usb_mount: Path | None = None` (referenz auf aktuellen USB-Mount).
    - `self._import_plan: ImportPlan | None = None`.
    - `self._rb6_db = None` (Rekordbox6Database — lazy-open beim Import).

    In _on_db_loaded: Referenz speichern: `if isinstance(db, PdbDatabase): self._pdb_db = db`. Auch `self._usb_mount` aus USBScanner ermitteln: Mount-Punkt aus usb_combo currentData() lesen — `data = self.usb_combo.currentData(); self._usb_mount = data[0] if data else None`.

    Import-Button Enable-Logik (per Claude's Discretion): `self.playlist_panel.tree.itemChanged.connect(self._on_playlist_check_changed)`. `_on_playlist_check_changed(self, item)`: Iteriere alle TopLevel-Items und Kinder — wenn min. eines gecheckt: `self.import_btn.setEnabled(True)`, sonst False. ToolTip im enabled Zustand entfernen.

    Handler `_on_import_clicked(self)`:
    - Wenn `self._pdb_db is None or self._usb_mount is None`: `logger.error("No USB database loaded"); return`.
    - `controller = ImportController(self._pdb_db, self._usb_mount)`.
    - Preflight: `error = controller.run_preflight()`. Wenn error: `logger.error("Import blocked: %s", error)` und return (kein Weiterschalten — per D-13, SAFE-01).
    - Ausgewählte Playlist-IDs aus Playlist-Panel ermitteln: `selected_ids = self._get_checked_playlist_ids()`.
    - Lokale master.db öffnen: `from pyrekordbox import Rekordbox6Database; self._rb6_db = Rekordbox6Database()`.
    - `self._import_plan = controller.build_import_plan(selected_ids, self._rb6_db)`.
    - `self._import_controller = controller`.
    - Backup-Pfad im Log anzeigen vor Summary (SAFE-03/D-14): `backup_path = ImportController.get_backup_path(); logger.info("Backup will be created at: %s", backup_path)`.
    - Summary-Panel anzeigen: `self.track_panel.populate_import_summary(self._import_plan, backup_path_str=str(backup_path))` (per D-01, D-03, SAFE-03).
    - Back-Button und Confirm-Button verdrahten: `self.track_panel.back_clicked.connect(self._on_import_back)` und `self.track_panel.confirm_clicked.connect(self._on_confirm_import)` — Verbindungen nach restore_browse_mode wieder trennen.

    Handler `_on_import_back(self)`:
    - `self.track_panel.restore_browse_mode()`.
    - Signale trennen: `self.track_panel.back_clicked.disconnect(self._on_import_back)` und entsprechend confirm.

    Handler `_on_confirm_import(self)`:
    - Force-Import-Selections aus Summary lesen: `selections = self.track_panel.get_import_selections()`. `self._import_plan.force_import_ids = {tid for tid, will in selections.items() if will and self._import_plan.track_statuses.get(tid) == TrackImportStatus.DUPLICATE}`.
    - `worker = _ImportWorker(self._import_controller, self._import_plan, self._rb6_db)`.
    - `worker.signals.progress.connect(lambda msg: logger.info("%s", msg))`.
    - `worker.signals.finished.connect(self._on_import_finished)`.
    - `worker.signals.error.connect(lambda err: logger.error("Import error: %s", err))`.
    - `QThreadPool.globalInstance().start(worker)`.
    - Import-Button und Confirm-Button deaktivieren während Import läuft.

    - `logger.info("Import complete — %d imported, %d skipped, %d failed. Backup: %s", result.imported_count, result.skipped_count, result.failed_count, result.backup_path)`.
    - `self.track_panel.restore_browse_mode()`.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| PlaylistPanel checkbox state → import_controller | Ausgewählte Playlist-IDs aus UI werden an Core weitergegeben |
| QRunnable Background-Thread → QLogHandler | Logging aus Worker-Thread muss via Qt-Signal auf Main-Thread relayiert werden |
| Rekordbox6Database() ohne Path → master.db | Öffnet lokale master.db; muss geschlossen sein |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-05-01 | Tampering | Rekordbox läuft während Import | mitigate | run_preflight() + db.commit() interner Guard; kein Write ohne grünen Preflight (SAFE-01) |
| T-02-05-02 | Tampering | QRunnable Background cross-thread Widget-Zugriff | mitigate | _ImportWorker verwendet nur _ImportSignals (QObject); keine direkten Widget-Zugriffe aus run(); alle UI-Updates via Signal→Slot auf Main-Thread |
| T-02-05-03 | Tampering | Doppelter Confirm-Klick | mitigate | Confirm-Button und Import-Button werden deaktiviert sobald Worker gestartet; reaktivierung nur in _on_import_finished |
| T-02-05-04 | Denial of Service | USB abziehen während Import läuft | mitigate | add_content FileNotFoundError wird im Worker abgefangen; db.rollback() + error-Signal → Fehlermeldung im Log (Pitfall 1 aus RESEARCH) |
| T-02-05-SC | Tampering | pip installs | accept | Keine neuen Packages |
