## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| USB TrackRow.file_path → abs_path Konstruktion | Relativer Pfad aus nicht-vertrauenswürdiger USB-Quelle wird zu absolutem Pfad |
| USB-Track → DjmdContent in master.db | Track-Metadaten aus USB werden in lokale Rekordbox-DB geschrieben |
| Rekordbox-Prozess-Check → Import-Entscheidung | OS-Prozessliste entscheidet ob Write erlaubt ist |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-02-01 | Tampering | import_controller build_import_plan | mitigate | Path-Traversal-Guard: `resolved = (mount / file_path.lstrip('/')).resolve(); assert str(resolved).startswith(str(mount.resolve()))` — blockiert "../../../etc/passwd"-Pfade aus präpariertem PDB |
| T-02-02-02 | Tampering | import_controller SQL via title/artist | accept | SQLAlchemy ORM-Queries sind parametrisiert — keine SQL-Injection möglich |
| T-02-02-03 | Tampering | import_controller write während RB läuft | mitigate | run_preflight() + db.commit() interner Guard (D-13, SAFE-01) |
| T-02-02-04 | Tampering | import_controller partial write | mitigate | SQLAlchemy-Session wraps alle Writes; db.rollback() im except-Block (D-15, SAFE-04) |
| T-02-02-05 | DoS | import_controller add_content path.stat() | mitigate | Pitfall 1: USB-Mount-Check in run_preflight(); FileNotFoundError wird als ImportError geloggt und nicht re-raised (Track wird übersprungen) |
| T-02-02-SC | Tampering | pip installs | accept | Keine neuen Packages — kein slopcheck |
</threat_model>
